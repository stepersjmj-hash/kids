# 우리집 재생목록 (kids)

아이에게 **내가 고른 유튜브 영상만** 연속 재생해 주는 웹페이지입니다.
목록에 없는 추천 영상은 끼어들지 않고, 끝화면 추천도 검은 덮개로 가린 뒤 바로 다음 영상으로 넘어갑니다.

- 접속: https://stepersjmj-hash.github.io/kids/
- TV 모드로 바로 열기: https://stepersjmj-hash.github.io/kids/?tv=1

## TV 앱 (Chromecast with Google TV)

PC 없이 TV 리모컨만으로 보는 앱입니다. 목록은 구글 드라이브 동기화로 폰과 같습니다.

| 리모컨 | 동작 |
|---|---|
| ← / → | 화면 아래 세 버튼(이전 · 재생 · 다음) 사이에서 고르기 (노란 링). 버튼 옆에 이전·다음 영상 썸네일이 보입니다 |
| 가운데 버튼 | 고른 버튼 누르기 |
| ↓ (또는 ↑) | **골라 보기** 열기: 영상이 3×2 격자로 나오고 ←→↑↓ 로 이동, 가운데 버튼 재생. 줄 끝에서 더 누르면 다음 페이지·반대쪽으로 순환. 맨 위 칩 줄: 처음부터 다시(반복) · 섞어서(셔플) · 새로고침 · 전체화면 · 로그인 |
| 뒤로 | 골라 보기 닫기 · 전체화면 해제 · 그다음 두 번 누르면 종료 |

- 제목 옆 점: 초록 = 본 영상, 빨강 = 지금, 베이지 = 남은 영상 (25개 넘으면 "3 / 40" 숫자). 아래 빨간 막대는 재생 위치.
- 전체화면(골라 보기 → 전체화면 칩): 영상만 화면 가득. 이때 ←/→ 이전·다음, 가운데 재생·정지, ↓ 골라 보기.
- PC 브라우저에서 TV 화면을 미리 보려면 주소 뒤에 `?app=1` (키보드 방향키·Enter·Esc 가 리모컨, 로그인은 안 됨).
- ←/→ 를 빠르게 **두 번** 누르면 10초, **세 번** 누르면 30초 뒤로·앞으로 (그 뒤 한 번마다 +10초). 한 번 누르기는 0.2초 뒤에 실행됩니다.

- 새로고침(골라 보기 칩): 폰에서 방금 추가한 영상·새 버전을 바로 받아옵니다 (보던 영상부터 이어 재생).
- 10분 넘게 다른 앱에 있다 돌아오면 자동으로 새로 고칩니다.
- 처음 실행하면 QR과 코드가 뜹니다. 폰으로 QR을 찍거나 google.com/device 에서 코드 입력 → 같은 구글 계정으로 허용. 코드가 만료되면 가운데 버튼으로 새 코드.
- 앱을 켜면 목록 첫 영상부터 자동 재생됩니다.
- 설치·빌드 방법은 `android-tv/` 와 CLAUDE.md 참고 (개발자용).

## 추천: 구글 드라이브 동기화 (폰·PC 같은 목록)

아동용(Made for Kids) 영상은 유튜브 재생목록 저장·좋아요 기록이 막혀 있어서,
**이 페이지의 목록을 기준으로 쓰고 기기 간에는 구글 드라이브로 맞춥니다.**

1. 폰(아이폰 사파리)과 PC 크롬에서 각각 페이지를 열고 **Google 로그인** (같은 계정).
   권한 화면에서 "Google Drive 앱 데이터" 항목도 허용.
2. "☁ 드라이브 동기화 켜짐" 이 보이면 연결된 것입니다.
3. 폰 유튜브 앱 → 영상 → **공유 → 링크 복사** → 페이지 입력칸에 붙여넣기 → **추가**.
4. PC는 화면으로 돌아오거나 1분마다 자동으로 반영합니다.

- 목록은 내 구글 드라이브에 `우리집 재생목록 (동기화).json` 파일로 저장됩니다. **지우거나 이름을 바꾸지 마세요** (TV 앱과 같이 씀). 이 앱은 자기가 만든 이 파일만 볼 수 있습니다.
- 로그인은 약 1시간 유지됩니다. 만료되면 동기화만 멈추고 재생은 계속되며, 로그인을 다시 누르면 이어서 맞춥니다.
- 아이폰: 사파리 공유 → **홈 화면에 추가** 해 두면 앱처럼 열 수 있습니다.

## 유튜브에서 바로 보내기

페이지를 `?add=영상주소` 로 열면 그 영상이 추가됩니다. 이미 열려 있는 재생목록 탭이 있으면
그 탭에 넘기고 새 탭은 저절로 닫힙니다. 로그인은 1시간 동안 기억되므로 그 사이엔 바로 드라이브에 동기화됩니다.

### 아이폰 — 단축어로 공유 메뉴에 등록 (한 번만 설정)
1. **단축어** 앱 → 오른쪽 위 **+** → 이름을 `재생목록에 추가` 로.
2. 아래 ⓘ(세부 정보) → **공유 시트에서 보기** 켜기 → 완료.
   맨 위 "공유 시트에서 **입력 받기**"를 눌러 **URL** 과 **텍스트** 만 남기기.
3. 동작 추가: **URL 인코딩** (입력: *단축어 입력*).
4. 동작 추가: **URL** → 내용에 `https://stepersjmj-hash.github.io/kids/?add=` 입력 후 바로 뒤에 변수 **URL 인코딩된 텍스트** 넣기.
5. 동작 추가: **URL 열기**.

사용: 유튜브 앱 → 영상 → **공유** → (아래로 밀어) **더 보기** → **재생목록에 추가**.
처음 한 번은 "웹사이트를 열도록 허용" 확인이 나옵니다.

### PC — 북마크바 버튼
페이지 왼쪽 아래 안내의 **📌 재생목록에 추가** 를 북마크바로 끌어다 놓기.
유튜브 영상 페이지에서 그 북마크를 누르면 추가됩니다 (TV로 보내는 탭이 열려 있으면 거기로 들어감).

## 유튜브 재생목록 연결 (아동용이 아닌 영상)

PC를 건드리지 않고 **폰 유튜브 앱에서** 보여줄 영상을 관리하는 방법입니다.

1. 폰 유튜브 앱에서 영상 → **저장** → **새 재생목록** (예: "아기용", 공개 범위 **일부 공개**).
   보여주고 싶은 영상이 보일 때마다 **저장 → 아기용**.
2. 재생목록 → 공유 → 링크 복사 (`https://youtube.com/playlist?list=PL...`).
3. 이 페이지 입력칸에 그 링크를 붙여넣고 **추가** → "🔗 연결된 재생목록" 표시.
4. 이후에는 페이지를 열 때마다 재생목록 최신 내용으로 자동 갱신됩니다. 열어 둔 상태라면 **🔄 동기화**.

- 북마크용 주소: `https://stepersjmj-hash.github.io/kids/?tv=1&pl=재생목록ID`
- 재생목록이 **비공개**면 불러올 수 없습니다 (일부 공개·공개만 가능).
- 연결 중에는 목록이 재생목록 내용으로 덮어써집니다. 직접 추가한 영상까지 쓰려면 **연결 해제** 후 추가하세요.

## 로그인·로그아웃

- 목록 제목 옆 흰 버튼: 로그아웃 상태면 **Google 로그인**, 로그인 상태면 계정 사진과 함께 **로그아웃**.
  상태 줄에 로그인한 이메일이 표시됩니다.
- 로그아웃은 이 브라우저에서만 로그인 정보를 지웁니다. 목록은 남고, 다시 로그인하면 이어서 동기화됩니다.

## Google 로그인으로 가져오기 (좋아요·내 재생목록)

1. 도구 줄의 **유튜브에서 가져오기** (로그아웃 상태면 로그인부터 진행, TV 모드에서는 T로 목록을 다시 열어야 보임) → "확인되지 않은 앱" 경고가 나오면 **고급 → 이동** → 권한 허용.
2. 👍 좋아요 표시한 동영상 / 📁 내 재생목록(비공개 포함) 중에서 골라
   **추가**(뒤에 붙이기) · **바꾸기**(교체) · **🔗 연결**(공개·일부 공개만, 자동 동기화).
3. 로그인은 약 1시간 유지되며, 그 시간 동안만 이 브라우저에 기억됩니다. 유튜브 권한은 읽기 전용입니다.

- 앱이 테스트 모드라 **등록된 계정만 로그인됩니다.** 다른 사람이 쓰려면 관리자가
  Google Cloud 콘솔 → Google 인증 플랫폼 → 대상 → 테스트 사용자에 Gmail을 추가해야 합니다 (최대 100명).
- 유튜브 **채널이 있는 계정**이어야 합니다. "Channel not found" 가 나오면 youtube.com → 프로필 → 채널 만들기, 또는 로그인할 때 채널이 있는 브랜드 계정을 고르세요.
- 나중에 볼 동영상·시청 기록·YouTube Kids 목록은 가져올 수 없습니다.

## 로컬에서 실행

`serve.bat` 더블클릭 → http://localhost:8765/ (Python 필요, 창을 닫으면 종료).

## 쓰는 법

1. 위 주소를 PC 크롬에서 엽니다.
2. 오른쪽 빨간 카드에 유튜브 URL(일반·shorts·youtu.be·embed) 또는 영상 ID를 붙여넣고 **넣기**.
   여러 개는 공백으로 구분해 한 번에 넣을 수 있습니다.
3. 목록에서 영상을 클릭하면 재생, 끝나면 목록 안에서만 다음 영상으로 넘어갑니다.
4. 크롬캐스트로 보내기: **T**(TV 모드) → **F**(전체화면) → 크롬 메뉴 ⋮ → **전송** → 기기 선택 → 소스: **탭 전송**.

목록은 브라우저(localStorage)에 자동 저장됩니다. 다른 PC/브라우저에서는 비어 있으니 아래 "목록 공유"를 쓰세요.

### 조작

| 키 | 동작 |
|---|---|
| Space / Enter | 재생·일시정지 |
| ← / → | 이전 / 다음 |
| L | 반복 (기본 켜짐) |
| S | 셔플 |
| T | TV 모드 (목록 숨김) |
| F | 전체화면 |

- PC: 목록 행을 **끌어다 놓아** 순서 변경, ✕로 삭제. 영상 아래 칩: 처음부터 다시(반복) · 섞어서(셔플) · TV 모드 · 전체화면.
- 폰: 오른쪽 ≡ 손잡이를 눌러 끌면 순서 변경, 행을 **왼쪽으로 밀면** 삭제. JSON·전체 삭제 같은 도구는 **도구 보기**를 누르면 나옵니다.

### 재생 불가 영상

업로더가 외부 삽입을 막은 영상은 자동으로 "⚠ 재생 불가" 표시 후 건너뜁니다. **재생불가 삭제** 버튼으로 한 번에 정리하세요.

## 목록 공유 — 로그인 없이 JSON 파일로 (대안)

1. **JSON 내보내기**로 `playlist.json`을 받습니다.
2. 이 저장소의 `playlist.json`을 그 내용으로 교체해 커밋합니다 (GitHub 웹에서 연필 아이콘으로 편집해도 됩니다).
3. 아래 주소로 열면 그 목록을 불러옵니다:
   `https://stepersjmj-hash.github.io/kids/?tv=1&list=https://stepersjmj-hash.github.io/kids/playlist.json`

`playlist.json` 형식: `[{ "id": "영상ID", "title": "제목" }]` (제목은 비워도 자동 조회), 또는 URL 문자열 배열.

## 참고

- 광고는 임베드 플레이어에도 붙습니다 (유튜브 프리미엄 미적용). 영상 시작 전 광고는 화면을 가리고 소리도 꺼 둡니다. 영상 중간 광고는 막을 수 없습니다.
- TV 앱에서는 보이지 않는 두 번째 플레이어가 다음 영상을 미리 받아 앞 광고를 소리 없이 흘려보낸 뒤 대기합니다. 그래서 영상이 끝나면 다음 영상이 광고 없이 바로 이어집니다 (첫 영상과, 목록에서 직접 고른 영상에는 광고가 나올 수 있음). PC·폰에서 써 보려면 주소 뒤에 `?preload=1`, TV에서 끄려면 `?preload=0`.
- 탭 전송이라 화질은 PC 성능·네트워크에 따라 다릅니다.
