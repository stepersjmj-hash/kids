# 우리집 재생목록 (kids)

아이에게 **내가 고른 유튜브 영상만** 연속 재생해 주는 웹페이지입니다.
목록에 없는 추천 영상은 끼어들지 않고, 끝화면 추천도 검은 덮개로 가린 뒤 바로 다음 영상으로 넘어갑니다.

- 접속: https://stepersjmj-hash.github.io/kids/
- TV 모드로 바로 열기: https://stepersjmj-hash.github.io/kids/?tv=1

## 쓰는 법

1. 위 주소를 PC 크롬에서 엽니다.
2. 오른쪽 입력칸에 유튜브 URL(일반·shorts·youtu.be·embed) 또는 영상 ID를 붙여넣고 **추가**.
   여러 개는 줄바꿈/공백으로 구분해 한 번에 넣을 수 있습니다.
3. 목록에서 영상을 클릭하면 재생, 끝나면 목록 안에서만 다음 영상으로 넘어갑니다.
4. 크롬캐스트로 보내기: **T**(TV 모드) → **F**(전체화면) → 크롬 메뉴 ⋮ → **전송** → 기기 선택 → 소스: **탭 전송**.

목록은 브라우저(localStorage)에 자동 저장됩니다. 다른 PC/브라우저에서는 비어 있으니 아래 "목록 공유"를 쓰세요.

### 조작

| 키 | 동작 |
|---|---|
| Space / Enter | 재생·일시정지 |
| ← / → | 이전 / 다음 |
| L | 반복 (기본 켜짐) |
| S | 셔플 |
| T | TV 모드 (목록 숨김) |
| F | 전체화면 |

목록 항목의 ▲▼로 순서 변경, ✕로 삭제.

### 재생 불가 영상

업로더가 외부 삽입을 막은 영상은 자동으로 "⚠ 재생 불가" 표시 후 건너뜁니다. **재생불가 삭제** 버튼으로 한 번에 정리하세요.

## 목록 공유 (다른 기기에서 같은 목록 쓰기)

1. **JSON 내보내기**로 `playlist.json`을 받습니다.
2. 이 저장소의 `playlist.json`을 그 내용으로 교체해 커밋합니다 (GitHub 웹에서 연필 아이콘으로 편집해도 됩니다).
3. 아래 주소로 열면 그 목록을 불러옵니다:
   `https://stepersjmj-hash.github.io/kids/?tv=1&list=https://stepersjmj-hash.github.io/kids/playlist.json`

`playlist.json` 형식: `[{ "id": "영상ID", "title": "제목" }]` (제목은 비워도 자동 조회), 또는 URL 문자열 배열.

## 참고

- 광고는 임베드 플레이어에도 붙을 수 있습니다.
- 탭 전송이라 화질은 PC 성능·네트워크에 따라 다릅니다.
