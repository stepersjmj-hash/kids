# 우리집 재생목록 (kids)

아이에게 **내가 고른 유튜브 영상만** 연속 재생해 주는 웹페이지입니다.
목록에 없는 추천 영상은 끼어들지 않고, 끝화면 추천도 검은 덮개로 가린 뒤 바로 다음 영상으로 넘어갑니다.

- 접속: https://stepersjmj-hash.github.io/kids/
- TV 모드로 바로 열기: https://stepersjmj-hash.github.io/kids/?tv=1

## 추천: 유튜브 재생목록 연결 (폰에서 영상 추가)

PC를 건드리지 않고 **폰 유튜브 앱에서** 보여줄 영상을 관리하는 방법입니다.

1. 폰 유튜브 앱에서 영상 → **저장** → **새 재생목록** (예: "아기용", 공개 범위 **일부 공개**).
   보여주고 싶은 영상이 보일 때마다 **저장 → 아기용**.
2. 재생목록 → 공유 → 링크 복사 (`https://youtube.com/playlist?list=PL...`).
3. 이 페이지 입력칸에 그 링크를 붙여넣고 **추가** → "🔗 연결된 재생목록" 표시.
4. 이후에는 페이지를 열 때마다 재생목록 최신 내용으로 자동 갱신됩니다. 열어 둔 상태라면 **🔄 동기화**.

- 북마크용 주소: `https://stepersjmj-hash.github.io/kids/?tv=1&pl=재생목록ID`
- 재생목록이 **비공개**면 불러올 수 없습니다 (일부 공개·공개만 가능).
- 연결 중에는 목록이 재생목록 내용으로 덮어써집니다. 직접 추가한 영상까지 쓰려면 **연결 해제** 후 추가하세요.

## Google 로그인으로 가져오기 (좋아요·내 재생목록)

1. 목록 패널 제목 옆 흰색 **Google 로그인** 버튼 → 구글 계정 로그인 (TV 모드에서는 T로 목록을 다시 열어야 보임) → "확인되지 않은 앱" 경고가 나오면 **고급 → 이동** → 권한 허용.
2. 👍 좋아요 표시한 동영상 / 📁 내 재생목록(비공개 포함) 중에서 골라
   **추가**(뒤에 붙이기) · **바꾸기**(교체) · **🔗 연결**(공개·일부 공개만, 자동 동기화).
3. 로그인은 약 1시간 유지되며 브라우저에 저장되지 않습니다. 권한은 읽기 전용입니다.

- 앱이 테스트 모드라 **등록된 계정만 로그인됩니다.** 다른 사람이 쓰려면 관리자가
  Google Cloud 콘솔 → Google 인증 플랫폼 → 대상 → 테스트 사용자에 Gmail을 추가해야 합니다 (최대 100명).
- 나중에 볼 동영상·시청 기록·YouTube Kids 목록은 가져올 수 없습니다.

## 로컬에서 실행

`serve.bat` 더블클릭 → http://localhost:8765/ (Python 필요, 창을 닫으면 종료).

## 쓰는 법

1. 위 주소를 PC 크롬에서 엽니다.
2. 오른쪽 입력칸에 유튜브 URL(일반·shorts·youtu.be·embed) 또는 영상 ID를 붙여넣고 **추가**.
   여러 개는 줄바꿈/공백으로 구분해 한 번에 넣을 수 있습니다.
3. 목록에서 영상을 클릭하면 재생, 끝나면 목록 안에서만 다음 영상으로 넘어갑니다.
4. 크롬캐스트로 보내기: **T**(TV 모드) → **F**(전체화면) → 크롬 메뉴 ⋮ → **전송** → 기기 선택 → 소스: **탭 전송**.

목록은 브라우저(localStorage)에 자동 저장됩니다. 다른 PC/브라우저에서는 비어 있으니 아래 "목록 공유"를 쓰세요.

### 조작

| 키 | 동작 |
|---|---|
| Space / Enter | 재생·일시정지 |
| ← / → | 이전 / 다음 |
| L | 반복 (기본 켜짐) |
| S | 셔플 |
| T | TV 모드 (목록 숨김) |
| F | 전체화면 |

목록 항목의 ▲▼로 순서 변경, ✕로 삭제.

### 재생 불가 영상

업로더가 외부 삽입을 막은 영상은 자동으로 "⚠ 재생 불가" 표시 후 건너뜁니다. **재생불가 삭제** 버튼으로 한 번에 정리하세요.

## 목록 공유 (다른 기기에서 같은 목록 쓰기)

1. **JSON 내보내기**로 `playlist.json`을 받습니다.
2. 이 저장소의 `playlist.json`을 그 내용으로 교체해 커밋합니다 (GitHub 웹에서 연필 아이콘으로 편집해도 됩니다).
3. 아래 주소로 열면 그 목록을 불러옵니다:
   `https://stepersjmj-hash.github.io/kids/?tv=1&list=https://stepersjmj-hash.github.io/kids/playlist.json`

`playlist.json` 형식: `[{ "id": "영상ID", "title": "제목" }]` (제목은 비워도 자동 조회), 또는 URL 문자열 배열.

## 참고

- 광고는 임베드 플레이어에도 붙을 수 있습니다.
- 탭 전송이라 화질은 PC 성능·네트워크에 따라 다릅니다.
